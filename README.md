# Thanuja M — Professional Portfolio

A modern, hiring-ready portfolio built with **React**, **Tailwind CSS**, **Vite**, and **Firebase Firestore**.

## Features

- Professional dark theme with Tailwind CSS v4
- Fully responsive design with smooth Framer Motion animations
- **Firestore integration** for dynamic content & contact form
- Latest resume data: Geesesquads experience, NestJS, AWS, AI/RAG skills
- Key projects: Field Pulse, CareerHive, AI Asset Assistant
- Resume download button (`/Resume.pdf`)
- Fallback to local data when Firebase is not configured

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Firebase Setup

1. Create a project at [Firebase Console](https://console.firebase.google.com)
2. Enable **Cloud Firestore**
3. Copy `.env.example` → `.env` and add your config
4. Run `npm run seed` for Firestore document templates

## Tech Stack

- React 19 + Vite 7
- Tailwind CSS v4
- Firebase Firestore
- Framer Motion + Lucide Icons

## Deploy

```bash
npm run build
# Deploy dist/ to Vercel, Netlify, or Firebase Hosting
```
